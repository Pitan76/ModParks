# ModParks 機能一覧

## アカウント

- GitHub/Googleでのソーシャルログイン
- メール/パスワード認証
- パスワードリセット
- 2FA (TOTP)
- パスキー認証 (WebAuthn)
- プロフィール編集
- APIキー管理（開発者設定タブ）
- OAuth 2.0 / OIDC 提供（他サービスとの連携、ソーシャルログイン提供）
  - OAuthアプリの登録/編集/シークレット再発行/削除
  - 同意画面と、連携中アプリの解除
- 退会/データエクスポート
- ピン留め機能 (プロフィール)

## プロジェクト

- 作成（名前/スラッグ/説明/アイコン/タグ/ライセンス/ソースコードURL）
- 公開状態（公開/限定公開/非公開/下書き）
- メンバー管理/権限移譲
- 依存関係（CurseForge/Modrinth の mod も指定可）
- スクリーンショット（featured でカルーセル掲載を選択、最大12枚）
- 対応 Minecraft バージョン/プラットフォームのバッジ表示（サイドバー）
- AI 生成ラベルの表示（設定で表示のオン/オフ）
- プロジェクト単位で AI 翻訳の可否を切り替え

## バージョン

- 登録（バージョン番号/Minecraftバージョン/ローダー/更新内容）
- ダウンロード方式：アップロード/外部URL（GitHub Releases/Modrinth/CurseForge）
- プレリリース/ベータのチャネル区分
- チェンジログの Markdown 対応
- jar メタデータ自動入力（fabric.mod.json/mods.toml/quilt.mod.json/plugin.yml）
- ファイル SHA-256 の算出/表示

## 対応コンテンツ
MOD/プラグイン/リソースパック/データパック/シェーダ/MODパック/その他

## 検索/閲覧

- 名前検索
- 表記ゆらぎ対応の日本語検索（ひらがな/カタカナ、全角/半角を吸収）
- 種類/ローダー/タグでのフィルタ
- カテゴリ別表示（便利系/建築系/冒険系/工業系/魔術系/その他）
- 並び替え（ダウンロード数/新着/更新）
- カード/リスト表示切り替え
- レシピ表示（jar からクラフティングレシピを自動抽出し R2/CDN 配信、手動登録不要）
- Modrinth/CurseForge からの一括インポート

## カート

- プロジェクトカードからカートに追加/削除（カード上のカートボタン）
- カート内容は localStorage に保存（ブラウザ単位で永続）
- カートドロワー（ヘッダーのカートアイコン、モバイルはサイドバーから）
- カート内のアイテムからプロジェクトページへ遷移
- 一括ダウンロード（ローダー/Minecraftバージョンを指定可。合致するバージョンが無い場合は最新版）
- カートを空にする
- 設定 > テーマ からカート機能自体のオン/オフ
- ダウンロード履歴

## コミュニティ

- アイデア投稿/いいね/コメント
- アイデアのステータス管理（募集中/開発中/リリース済み）
- 「このアイデアから生まれた Mod」バッジ
- プロジェクトへのコメント
- ユーザー/プロジェクトのフォロー
- お気に入り
- コレクション/マイリスト（公開/共有）

## 翻訳

- 説明文の AI 多言語翻訳（閲覧者が実行、ログイン必須・公開プロジェクトのみ）
- 原文は据え置き、訳文は別テーブルで保持。原文の言語は本文から推定し作者が上書き可
- 記法（markdown/plaintext/pukiwiki）をトークンへマスクして渡し、崩れた行は原文のまま残す
- タイトルは訳さない（Mod 名は固有名詞のため）
- 作者による手動翻訳の登録/確定/削除、AI 下書きからの取り込み
- 原文更新時は訳文を消さず stale 判定。手動訳は自動で上書きしない
- 一覧/OGP は訳文を表示。hreflang と sitemap は原文と手動訳のみに絞る
- 管理画面からモデル/分割文字数/実行回数上限/機能全体の有効化を設定

## パフォーマンス

- 画像サムネイル配信（Cloudflare Image Transformations、幅を固定値に制限）
- 読み取り API への Cache-Control 付与、マスタデータのキャッシュ
- 画像の遅延読み込みと明示サイズ指定
- スケルトンローディング（一覧/プロフィール/プロジェクトのタブ）

## 開発者体験 (DX)

- GitHub 連携（OAuth/リポジトリ紐づけ）
- GitHub Release の自動同期（Webhook/Cron）
- CurseForge 作者の所有確認（チャレンジコード方式）
- Modrinth/CurseForge とのダウンロード数同期
- ダウンロード統計ダッシュボード（推移グラフ、日/週/月の粒度切替、プロジェクト別内訳）
- API 提供

## セキュリティ

- jar ヒューリスティックスキャン（同梱実行ファイル/zip slip/remote Class-Path 等）
  - malicious は配布遮断、suspicious は警告表示
  - 異議申請/管理者裁定フロー
- SHA-256 による検証
- 信頼スコア/段階（restricted/new/member/trusted/veteran）
  - 実行ファイル（.exe/.msi/.dmg/.app）のアップロードは member 以上に限定
  - マルウェア検知でスコアを失効。加減点は投稿者ではなくアップロード実行者に効く
- レート制限（IP + 識別子ベース）
- セキュリティヘッダ（CSP/HSTS/X-Frame-Options 等）
- DDoS 監視と自動解除（cron による状態チェック、管理画面から確認）
- 外部画像のプロキシ配信（閲覧者の IP/UA を画像ホストへ渡さない、SSRF 対策つき）

## 通報/管理

- 通報（著作権侵害/マルウェア疑い/スパム/その他）
  - 対象はプロジェクトのほか、ユーザー/コメント/アイデア
- 管理者ダッシュボード（通報/非公開化/ユーザー/アイデア）
  - スキャンログと異議裁定、信頼スコア、レシピ管理、OAuth アプリ、ランタイム設定、使用状況、ログ
- 監査ログ（設定変更/バックアップ/通報処理/非公開化/権限変更/スキャン異議裁定）
- 定期バックアップ（Google Drive 退避対応）
- 静的スナップショットの公開（障害時に閲覧できる読み取り専用ビュー。非公開化/削除も毎回全件照合で反映）

## 通知/連携

- 通知（新規MOD/コメント返信など）
- 更新通知（フォロー済みの新バージョン/Discord Webhook）
- SNS共有（Web Share API/OGP/Twitter Card）
- PWA プッシュ通知

## 共通基盤/その他
- 多言語化（日本語/英語）
  - 公開ページは URL で言語を分離（日本語は接頭辞なし、英語は `/en/...`）
  - 管理画面/設定など非公開ページは接頭辞なしに統一し、言語は Cookie で決定
- レスポンシブデザイン
- ダークモード
- SEO 対策（canonical/hreflang/sitemap の言語別出力、構造化データ、RSS）
- PWA 対応
- RSS フィード
- 広告位置プレビュー（config でオフ/プレビュー/オン切替）
- オンボーディングツアー
- 右クリックコンテキストメニュー（開く/コピー/共有など）
- クリエイターリワード（1ページ1広告からの収益の配布）
